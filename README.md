# CCG Plante

App mobile React Native (Expo) — projet CCG Plante (Collectible Card Game).

## Stack

- Expo SDK 54
- React Native 0.81
- React 19

## Prérequis

- Node.js 20+
- npm
- Pour iOS : Xcode installé (macOS)
- Pour Android : Android Studio + `ANDROID_HOME` configuré
- Pour tester sur téléphone : app **Expo Go**

## Installation

```bash
npm install
```

## Lancer l'app

```bash
npm run web       # navigateur
npm run ios       # simulateur iOS
npm run android   # émulateur Android
npm start         # QR code pour Expo Go
```

## Structure

```
App.js            # composant racine
index.js          # entrée Expo
app.json          # config Expo
assets/           # icônes, splash
```
